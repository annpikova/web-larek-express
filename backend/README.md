# Web-ларёк Backend

Backend для интернет-магазина "Web-ларёк" с JWT авторизацией и управлением товарами.

## Функциональность

- ✅ Создание и управление товарами (CRUD операции)
- ✅ JWT авторизация с refresh токенами
- ✅ Загрузка файлов изображений
- ✅ Создание заказов
- ✅ Валидация данных
- ✅ Централизованная обработка ошибок
- ✅ Логирование запросов и ошибок

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Убедитесь, что MongoDB запущена на порту 27017

4. Запустите сервер:
```bash
# Для разработки (с hot reload)
npm run dev

# Для продакшена
npm run start
```

## API Endpoints

### Товары
- `GET /product` - получить все товары
- `POST /product` - создать товар (требует авторизации)
- `PATCH /product/:productId` - обновить товар (требует авторизации)
- `DELETE /product/:productId` - удалить товар (требует авторизации)

### Авторизация
- `POST /auth/register` - регистрация пользователя
- `POST /auth/login` - вход в систему
- `GET /auth/token` - обновление токенов
- `GET /auth/logout` - выход из системы
- `GET /auth/user` - получение информации о текущем пользователе

### Заказы
- `POST /order` - создание заказа

### Загрузка файлов
- `POST /upload` - загрузка файла (требует авторизации)

## Технологии

- Node.js + Express
- TypeScript
- MongoDB + Mongoose
- JWT для авторизации
- Multer для загрузки файлов
- Celebrate + Joi для валидации
- Winston для логирования
